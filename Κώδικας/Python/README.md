# Εγκατάσταση περιβάλλοντος Python από αρχείο `requirements.txt`

Το αρχείο `requirements.txt` περιέχει τα πακέτα Python και τις εκδόσεις τους που απαιτούνται για την αναπαραγωγή ενός υπάρχοντος περιβάλλοντος σε άλλον υπολογιστή.

Οι παρακάτω οδηγίες αφορούν Windows.

## 1. Εγκατάσταση της Python ή του Anaconda

Στον νέο υπολογιστή πρέπει πρώτα να έχει εγκατασταθεί είτε:

- η Python, ή
- το Anaconda / Miniconda.

Για να επιβεβαιώσετε ότι η Python είναι διαθέσιμη, ανοίξτε **Command Prompt** ή **PowerShell** και εκτελέστε:

```bat
python --version
```

Για εγκατάσταση μέσω Conda, ελέγξτε επίσης:

```bat
conda --version
```

## 2. Μεταφορά του αρχείου

Αντιγράψτε το αρχείο:

```text
requirements.txt
```

στον νέο υπολογιστή, κατά προτίμηση μέσα στον φάκελο του έργου.

Παράδειγμα:

```text
C:\Projects\MyProject\requirements.txt
```

## 3. Μετάβαση στον φάκελο του έργου

Ανοίξτε **Command Prompt** και μεταβείτε στον φάκελο όπου βρίσκεται το αρχείο:

```bat
cd /d C:\Projects\MyProject
```

Η επιλογή `/d` επιτρέπει και την αλλαγή δίσκου, εφόσον χρειάζεται.

## 4. Δημιουργία νέου περιβάλλοντος

### Επιλογή Α: Χρήση Conda

Δημιουργήστε ένα νέο περιβάλλον, για παράδειγμα με Python 3.10:

```bat
conda create -n myenv python=3.10
```

Ενεργοποιήστε το:

```bat
conda activate myenv
```

Ελέγξτε ποια Python χρησιμοποιείται:

```bat
where python
```

Η πρώτη διαδρομή που εμφανίζεται πρέπει να αντιστοιχεί στο περιβάλλον `myenv`.

### Επιλογή Β: Χρήση του ενσωματωμένου `venv`

Δημιουργήστε το περιβάλλον:

```bat
python -m venv .venv
```

Ενεργοποιήστε το:

```bat
.venv\Scripts\activate
```

Μετά την ενεργοποίηση, στην αρχή της γραμμής εντολών θα πρέπει να εμφανίζεται κάτι παρόμοιο με:

```text
(.venv)
```

## 5. Αναβάθμιση του `pip`

Πριν από την εγκατάσταση των πακέτων, συνιστάται η αναβάθμιση του `pip`:

```bat
python -m pip install --upgrade pip setuptools wheel
```

## 6. Εγκατάσταση των απαιτούμενων πακέτων

Εκτελέστε:

```bat
python -m pip install -r requirements.txt
```

Η χρήση της μορφής:

```bat
python -m pip
```

είναι προτιμότερη από το απλό `pip`, επειδή εξασφαλίζει ότι χρησιμοποιείται το `pip` του ενεργού περιβάλλοντος Python.

## 7. Έλεγχος της εγκατάστασης

Για να εμφανίσετε τα εγκατεστημένα πακέτα:

```bat
python -m pip list
```

Για να ελέγξετε αν υπάρχουν ασυμβατότητες μεταξύ εξαρτήσεων:

```bat
python -m pip check
```

Αν η εντολή ολοκληρωθεί χωρίς σφάλματα, θα εμφανιστεί:

```text
No broken requirements found.
```

## 8. Δοκιμή του περιβάλλοντος

Εκτελέστε το κύριο πρόγραμμα του έργου, για παράδειγμα:

```bat
python main.py
```

ή ανοίξτε την Python:

```bat
python
```

και δοκιμάστε την εισαγωγή βασικών βιβλιοθηκών:

```python
import numpy
import scipy
import sklearn
```

Για έξοδο από την Python:

```python
exit()
```

## 9. Απενεργοποίηση του περιβάλλοντος

Για περιβάλλον Conda:

```bat
conda deactivate
```

Για περιβάλλον `venv`:

```bat
deactivate
```

## Πιθανά προβλήματα

### Ασυμβατότητα έκδοσης Python

Ορισμένα πακέτα μπορεί να απαιτούν συγκεκριμένη έκδοση Python. Ελέγξτε την έκδοση της αρχικής εγκατάστασης με:

```bat
python --version
```

Στον νέο υπολογιστή δημιουργήστε, κατά προτίμηση, περιβάλλον με την ίδια κύρια και δευτερεύουσα έκδοση, π.χ. Python 3.10.

### Αποτυχία εγκατάστασης συγκεκριμένου πακέτου

Μπορείτε να δοκιμάσετε την εγκατάστασή του ξεχωριστά:

```bat
python -m pip install package_name
```

Για συγκεκριμένη έκδοση:

```bat
python -m pip install package_name==1.2.3
```
